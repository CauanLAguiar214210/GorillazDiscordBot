# Formato

[[Reuniões|← Reuniões]]

Estrutura de uma nota de reunião (template em `Templates/Reunião.md`). Notas de reunião completam o [[Diário|Diário]] com decisões coletivas.

## Seções

| Seção | Conteúdo |
| --- | --- |
| Data e participantes | Quem esteve presente. |
| Pauta | Pontos discutidos (links para [[Decisões|decisões]]/[[Ideias|ideias]] quando houver). |
| Decisões | O que ficou decidido (se estrutural, abrir uma [[Decisões|ADR]]). |
| Pendências | Ações com responsável e prazo. |
| Links | Referências a PRs, reuniões anteriores etc. |

## Regras

- Título: `YYYY-MM-DD <tema curto>`.
- Não repetir conteúdo: ligue (wikilink) em vez de copiar.
- Pendências viram tarefas rastreáveis em [[Ideias|Ideias]] quando forem melhorias de produto.
