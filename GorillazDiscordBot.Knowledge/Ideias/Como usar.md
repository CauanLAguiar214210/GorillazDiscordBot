# Como usar

[[Ideias|← Ideias]]

## Status

| Status | Significado |
| --- | --- |
| `Ideia` | Anotada, ainda não priorizada. |
| `Priorizada` | Quer fazer em breve; pode ter prêmio de esforço/impacto. |
| `Em andamento` | Em desenvolvimento. |
| `Feita` | Concluída; manter nota para histórico (e link para o PR/nota relevante). |

## Regras

- Crie ideias com `Templates/Ideia.md`.
- Ao concluir, mova o status para `Feita` em vez de apagar.
- Ideias que viram decisão estrutural podem gerar uma [[Decisões|ADR]].
