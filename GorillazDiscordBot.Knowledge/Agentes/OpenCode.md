# OpenCode

Agente de codificação executado no terminal (CLI), usado para desenvolver e manter este repositório.

[[Agentes|← Agentes]] · [[Agentes/Qwen|Qwen]] · [[Agentes/Claude|Claude]]

## Sobre

- Interface por linha de comando, voltada a edição e análise de código.
- Opera com um modelo (`big-pickle`) e pode delegar subtarefas a subagentes.
- Executa comandos no ambiente do repositório (build, testes, git etc.).
