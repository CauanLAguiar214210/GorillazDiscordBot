# Formato da nota diária

[[Diário|← Diário]]

Cada nota diária fica em `Diário/YYYY-MM-DD.md` (padrão `YYYY-MM-DD`), criada pelo plugin de notas diárias com o template `Templates/Diária.md`.

## Estrutura sugerida

```markdown
# YYYY-MM-DD

## Feito
- ...

## Em andamento
- ...

## Bloqueios / decisões
- ...

## Topo de mente
- ...
```

Apague seções vazias na própria nota se preferir.
