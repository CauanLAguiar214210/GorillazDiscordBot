PASSO A PASSO PARA DEPLOY
--------------------------

PRÉ-REQUISITOS
  1. AWS CLI configurado (aws sts get-caller-identity)
  2. Terraform >= 1.5 instalado
  3. Docker instalado
  4. Conta no MongoDB Atlas (https://mongodb.com/atlas)

ETAPA 1 — MongoDB Atlas
  1.1  Criar conta/cluster M0 Sandbox (free)
  1.2  Criar database user (usuário + senha)
  1.3  Network Access → Add IP → 0.0.0.0/0 (Allow all)
  1.4  Clusters → Connect → Drivers → Copiar connection string
       Ex: mongodb+srv://usuario:senha@cluster0.xxxxx.mongodb.net/gorillazbot

ETAPA 2 — Preparar Terraform
  2.1  cp infra/terraform.tfvars.example infra/terraform.tfvars
  2.2  Editar infra/terraform.tfvars com seus valores reais
  2.3  terraform -chdir=infra init
  2.4  terraform -chdir=infra plan
  2.5  terraform -chdir=infra apply

ETAPA 3 — Preencher Secrets
  3.1  Acessar AWS Console → Secrets Manager
  3.2  Atualizar os 3 secrets com valores reais:
       - gorillaz-discord-bot/discord-token
       - gorillaz-discord-bot/owm-api-key
       - gorillaz-discord-bot/mongodb-connection
  OU via CLI (ver outputs do Terraform):
       aws secretsmanager put-secret-value \
         --secret-id arn:aws:secretsmanager:.../discord-token \
         --secret-string "seu-token-real"

ETAPA 4 — Push da primeira imagem Docker
  4.1  aws ecr get-login-password --region us-east-1 | docker login \
         --username AWS --password-stdin \
         <account-id>.dkr.ecr.us-east-1.amazonaws.com
  4.2  docker build -t gorillaz-discord-bot .
  4.3  docker tag gorillaz-discord-bot:latest \
         <account-id>.dkr.ecr.us-east-1.amazonaws.com/gorillaz-discord-bot:latest
  4.4  docker push \
         <account-id>.dkr.ecr.us-east-1.amazonaws.com/gorillaz-discord-bot:latest

ETAPA 5 — Verificar ECS
  5.1  Acessar AWS Console → ECS → gorillaz-discord-bot
  5.2  Ver se a tarefa está "RUNNING"
  5.3  Logs: CloudWatch → Log groups → /ecs/gorillaz-discord-bot

ETAPA 6 — CI/CD (GitHub Actions)
  6.1  Configurar GitHub Secrets:
       - AWS_ACCESS_KEY_ID
       - AWS_SECRET_ACCESS_KEY
       - AWS_REGION = us-east-1
       - ECR_REPOSITORY = gorillaz-discord-bot
       - ECS_SERVICE = gorillaz-discord-bot
       - ECS_CLUSTER = gorillaz-discord-bot
       - ECS_TASK_DEFINITION_ARN = gorillaz-discord-bot
  6.2  Criar environment "production" no repo GitHub
  6.3  Fazer push para dev → deploy automático

SEGURANÇA — PENDÊNCIAS
-----------------------
  ⚠️  Não há health check HTTP (bot não expõe porta)
      → Monitorar via CloudWatch Logs + Discord Gateway status

  ⚠️  Apenas 1 AZ (us-east-1a)
      → Se a AZ cair, o bot fica offline até recovery
